Icon-only control at the 44px touch floor; `label` is required (accessible name + tooltip). Use `ghost` for toolbars, `solid` for a primary transport control (play/pause).

```jsx
<IconButton label="השהה" icon={<PauseIcon/>} variant="solid" />
<IconButton label="סנן לפי תפקיד" icon={<FilterIcon/>} />
```

עקרונות עיצוב VetCrew

RTL-Native, Hebrew-First

תכנון בעברית באמצעות מאפיינים לוגיים (inset-inline-*, margin-inline). מראה אייקונים כיווניים בהתאם.

Severity is never hue-only

חומרת המצב אינה מקודדת על ידי צבע בלבד. כל רמה מלווה בצורה (SeverityGlyph) ייחודית ותווית טקסט.

Teal is for Action ONLY

צבע הטורקיז משמש אך ורק לפקודות ואינטראקציות. לעולם לא לחומרה או סטטוס.

Tabular metrics & AA

מספרים וערכים קליניים משתמשים בפונט condensed בעל רוחב ספרות קבוע למניעת רעידות וג'יטר (IBM Plex Sans Condensed).

פורטל מערכת העיצוב VetCrew

ברוכים הבאים לפורטל האינטראקטיבי המאגד את כל חוקי העיצוב, המרחב, הצבעים, רכיבי ה-React והמסכים המדומים של מוצר VetCrew. כל הרכיבים נבנו באופן התואם לשימוש בטאבלט, נגישות WCAG 2.1 AA, ותמיכה מלאה ב-RTL.

הנחיות עיצוב וטוקנים (Guidelines & Tokens)

צבעים ניטרליים (Neutrals)

Color

סקאלת צבעים ניטרליים קליניים: Cool Matte Clinical Neutrals וסקאלת desaturated "monitor dark".

פתח הנחיה

צבעי משטחים (Surfaces)

Color

חלוקת משטחים, פנלים, כרטיסים, ורכיבים קליניים. הגדרת חפיפת צבעי מכשור מול צבעי תוכנה מטים.

פתח הנחיה

צבעי אינטראקציה (Action & Teal)

Color

הגדרת שימוש ייעודי בטורקיז (Teal) לאלמנטים פעיליים ומקשי אינטראקציה בלבד.

פתח הנחיה

רמפת חומרה ואזעקה (Severity)

Severity

הגדרת 4 רמות החומרה הקליניות (normal, watch, elevated, critical) והתאמתן לתקינה הקלינית.

פתח הנחיה

סקאלת מרווחים (Space Scale)

Layout

סקאלת מרווחים המבוססת על כפולות של 4px. טוקני space-1 עד space-16 עבור פריסות מהודקות.

פתח הנחיה

רדיוסי פינות (Corner Radii)

Layout

חוקי רדיוס קונצנטריים למניעת התנגשויות ויזואליות: xs, sm, md, lg, pill.

פתח הנחיה

טיפוגרפיה ופונטים

Fonts

חלוקת משפחות הפונטים: IBM Plex Sans Hebrew לממשק, ו-IBM Plex Sans Condensed לערכים קליניים.

פתח הנחיה

סימולציית עיוורון צבעים (CVD)

Accessibility

מבדק עיוורון צבעים (פרוטנופיה/דאוטרנופיה) לרמפת החומרה והוכחת עמידה ב-Redundancy.

פתח הנחיה
כרטיסי רכיבי React (Component Cards)

מקשים ובקרים (Controls)

React

צפייה ברכיבי Button, IconButton, AntsRating ו-InjectionTrigger בפעולה.

פתח כרטיס רכיב

אינדיקציות וסטטוס (Status)

React

צפייה ברכיבי SeverityChip, ConnectionPill, וסמן שלבי הסימולציה במחזור החיים.

פתח כרטיס רכיב

כרטיסי מדדים (Vital Cards)

React

רכיב VitalCard קומפקטי קשיח, הכולל אינדיקציית הבזק שינוי ערך, מצב stale, ונגישות מלאה.

פתח כרטיס רכיב

כרטיסי משימות (Task Chips)

React

רכיב TaskChip המיועד לדרג הבסיס, תומך בקידוד צבעי משימה, מצבי ביצוע, נעילה, ודיווח ערכים.

פתח כרטיס רכיב

ציר תחקיר (Timeline Scrubber)

React

רכיב TimelineScrubber לצפייה אסינכרונית בתחקיר (AAR) - ציר זמן מבוסס תפקידים וציונים.

פתח כרטיס רכיב

מוניטור החולה (Patient Monitor)

React Canvas

רכיב PatientMonitor המדמה את מוניטור uMEC12, תומך ב-5 ערוצי גלי sweep מהירים ועמודת ערכים.

פתח כרטיס רכיב
תחנות עבודה ומסכי סימולציה (UI Kits)

תחנת המתאמן (Trainee Station)

Full Screen

תצוגת המתאמן המציגה את מצב החולה הנוכחי, המדדים שלו, ופנל משימות מבוסס דרג בסיס.

פתח סימולציה

קונסולת המדריך (Instructor Console)

Full Screen

קונסולת בקרה צפופה המיועדת להזרקת אירועים בזמן אמת, מעקב אחר שלבי סשן ואינטגרציית ציוני ANTS.

פתח סימולציה

צופה תחקיר (AAR Replay Viewer)

Full Screen

כלי תחקור אסינכרוני מבוסס ערכת נושא בהירה, המציג סקראבר אינטראקטיבי המקושר לאירועי ביצוע ודירוגים.
